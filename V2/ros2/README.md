# V2 ROS 2 模擬：底座 + 兩支 RS007L

在 WSL（Ubuntu 24.04 + ROS 2 Jazzy）用 RViz 顯示機器人底座，立柱頂端兩側各側裝一支 Kawasaki RS007L，加上煎台。
用吋動面板像教導器一樣操作：軸、基座、工具、世界四種座標，煎台位置可以隨時調整並存檔。

## 第一次安裝

在 Windows 終端機執行（會下載 Kawasaki 官方 RS007L 模型到 WSL 的 `~/smartcook_ws`，並編譯）：

```bash
wsl -d Ubuntu -- bash /mnt/d/smartcook/V2/ros2/setup_wsl.sh
```

## 開啟模擬

```bash
wsl -d Ubuntu -- bash -c "source ~/smartcook_ws/install/setup.bash && ros2 launch smartcook_v2_description display.launch.py"
```

會開兩個視窗：RViz（3D 畫面）和「SmartCook V2 吋動面板」。

不要再加最早版本的 `mount_x:=… mount_y:=0.0 mount_z:=1.204 mount_yaw:=…`：那是手臂裝在立柱頂端時的參數，
現在會把兩支手臂裝到立柱裡、一直顯示干涉。launch 看到 `mount_x` / `mount_yaw` 會直接報錯。
同一時間也只開一份模擬（兩份會搶著發 `/joint_states`）。

### RViz 滑鼠操作

| 動作 | 滑鼠 |
|---|---|
| 旋轉視角 | 左鍵拖曳 |
| 平移畫面 | 右鍵拖曳（中鍵拖曳也可以） |
| 拉近 / 拉遠 | 滾輪 |

這是 `smartcook_rviz_plugins/RightPanOrbit` 視角（RViz 預設 Orbit 的右鍵是縮放，這裡改成平移）。
畫面跑掉時，在 RViz 右側 Views 面板按「Zero」重設。

## 吋動面板

1. 選手臂：右臂 (+X) / 左臂 (-X)
2. 選座標：

   | 模式 | 6 個按鈕 | 方向依據 |
   |---|---|---|
   | 軸 | JT1～JT6 | 各軸單獨轉 |
   | 基座 | X Y Z Rx Ry Rz | 所選手臂自己的 base_link（側裝，所以 Z 是水平朝外） |
   | 工具 | X Y Z Rx Ry Rz | TCP 自己的軸 |
   | 世界 | X Y Z Rx Ry Rz | 地面座標（Z 朝上，X/Y 同 CAD） |

   直線移動和旋轉都以 TCP 為中心，姿態不變時只平移。
3. 按住 − / + 就會持續動，放開就停。速度滑桿 100% = 直線 100 mm/s、旋轉 30°/s、軸 30°/s。
4. 面板會顯示：
   - 各軸角度
   - TCP 位置分別在「基座」「世界」「煎台」三種座標下的 X Y Z（mm）和 O A T（deg）
     - O A T 和 Kawasaki 教導器一樣是 ZYZ 尤拉角
     - 煎台座標的原點是煎台頂面中心，可以直接看 TCP 離煎台多遠
5. 碰到軸極限會停住並顯示是哪一軸；接近奇異點（例如手臂伸直）時會提醒，TCP 可能跟不上指令。

「回原點」把兩支手臂所有軸歸零（手臂水平往外伸）。

### 直接輸入軸角度

「軸角度輸入」欄可以直接打所選手臂 JT1～JT6 的角度（deg）：

- 輸入範圍就是各軸極限，打超過會自動改成極限值。
- 按「移動到輸入角度」，六軸會同步移動到目標，速度依速度滑桿（最慢的軸 30°/s × 速度%）。途中每一步都做碰撞檢查，會撞到就停在途中並顯示原因。
- 「讀取目前角度」把輸入框填回手臂現在的角度；切換手臂時會自動讀取。
- 「停止」或按任何吋動按鈕會中斷移動。

### 碰撞檢查

手臂（link1～link6）和工具（平鏟、夾爪）不能穿過下面這些東西：

| 對象 | 檢查方式 |
|---|---|
| 煎台、取料托盤 | 手臂檢查點進入「方塊 + 安全距離」；工具不留安全距離，可以貼著表面但不能壓進去 |
| 立柱 / 底座 | 手臂、工具檢查點離底座模型表面小於安全距離 |
| 另一支手臂 | 檢查點離另一支手臂（含它的工具、固定在立柱上的 base_link）表面小於安全距離 |
| 地面 | 檢查點低於 z = 0 |

- 每個連桿、底座的 3D 模型表面約每 5 mm 取一個檢查點。
- 立柱和另一支手臂是「點對點」的距離，安全距離設小於 10 mm 時，這兩項仍以 10 mm 檢查（取樣間距的 2 倍），避免漏檢。
- 會碰到的吋動（軸、基座、工具、世界模式、回原點都一樣）會直接擋下，面板顯示是哪個連桿，例如「停止：link4 會碰到煎台」。
- 已經在干涉中時（例如把煎台移到手臂上），煎台面變紅、面板顯示「⚠ 干涉中」，只允許讓干涉變少的動作，往外移就能脫離。
- 安全距離預設 10 mm，面板上可以改，也可以暫時關閉檢查；按「儲存設定」會一起存。

還沒檢查的：

- **同一支手臂自己的連桿互撞**（例如 link5 折回去碰 link2，或鏟子碰到自己的手臂）：沒有檢查，目前只靠軸極限。

## 平鏟

兩支手臂預設都裝同一組參數化平鏟（在面板「工具」欄可以換）：法蘭座 → 把手（沿法蘭 Z 軸）→ 彎折 → 鏟面。

```
 法蘭  法蘭座      把手                  ╲
  ┃▌▌▌▌▌━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━●╲  彎角 α：鏟面放平時把手抬起的角度
                                          ╲▁▁▁▁▁▁▁▁▁▁▁▁▁▁ ← 鏟尖 = TCP
```

| 參數 | 預設 | 說明 |
|---|---|---|
| 鏟面寬 / 長 / 厚 | 140 / 150 / 2 mm | 長度從彎折處量到鏟尖 |
| 彎角 | 30° | 鏟面放平時把手和鏟面的夾角 |
| 把手長 / 徑 | 150 / 20 mm | 從法蘭座到彎折處 |
| 法蘭座徑 / 厚 | 63 / 12 mm | 接手臂 link6 法蘭 |

- 在面板「平鏟」欄改尺寸，RViz 和碰撞檢查會立刻更新；按「儲存設定」存到 `config/scene.yaml`。
- 鏟面頂面貼在把手下緣，鏟面放平時把手不會比鏟面低。

### 工具座標（TCP）

TCP 在**鏟尖中心、鏟面底面上**：

| 軸 | 方向 | 工具模式吋動的意思 |
|---|---|---|
| X | 從彎折處往鏟尖 | +X 往前鏟進肉排底下 |
| Y | 和 link6 的 Y 相同 | 左右平移 |
| Z | 鏟面底面朝外（放平時朝下） | +Z 往下壓、-Z 抬起；Ry 調鏟尖上下 |

### 匯出 STL

按「匯出 STL」會把目前尺寸存成 `V2/圖檔/spatula.stl`，單位 mm，原點在法蘭面中心、Z 軸朝外（和 link6 法蘭座標相同），可以匯入 IRONCAD 當機構設計的起點。

### 已知

- 預設尺寸下，右臂把鏟面放平在煎台中心附近時，鏟尖朝向 +Y、-X、-Y（90°～270°）都到得了；朝 +X（遠離立柱）會碰到 JT5 極限。

## 工具

兩支手臂預設都裝平鏟。面板「工具」欄可以把任一支換成夾爪（備用，目前覺得夾生肉排不實際）。

| 動作 | 用哪支 |
|---|---|
| 取料、完整流程 | 兩支都是平鏟：左鏟接著端、右鏟刮（完整流程放下後由左鏟直接翻面）；有一支是夾爪：用夾爪夾 |
| 單獨按「翻面」 | 裝平鏟的那支；兩支都是平鏟時用面板目前選的那支 |

夾爪是參數化平行雙指（本體 200 × 50 × 40、夾指 80 × 60 × 6、最大張開 160 mm），TCP 在兩指指尖中心，「匯出 STL」存成 `V2/圖檔/gripper.stl`。

## 取料托盤

生肉排平放在托盤上，沿托盤長邊排成一排（預設 3 片、間距 140 mm），從第一片開始拿。
托盤預設在煎台右前角：頂面中心 X 450、Y 950、高 850 mm，450 × 200 × 20 mm（長邊沿 X）。
位置、尺寸、片數、間距都在面板「取料托盤」欄調整；托盤也是碰撞物（平鏟可以貼著托盤面，手臂要留安全距離）。

試過的托盤位置（左鏟接、右鏟刮，兩支手臂從原點姿態出發）。看的是右鏟從托盤移到煎台擋肉排那一段：

| 托盤中心 (X, Y) | 結果 |
|---|---|
| (450, 950) 煎台右前角 | 最順（預設）：右鏟移動 0.57 m，最大轉 88° |
| (650, 650) 煎台右邊偏前 | 順：0.86 m，最大轉 88° |
| (600, 450)、(550, 250) 煎台右邊 | 可以但很怪：右鏟繞 3.5 m，JT3、JT5 翻轉 200° 以上 |
| (0, −550)、(450, −450) 立柱後面 | 可以：1.7 m，JT1、JT4 轉 160° |
| (0, 1000)、(−600, 450) | 不行：右鏟到不了 |

托盤換位置後要再看一次動作順不順。

## 取料、翻面

面板「肉排」欄：

| 按鈕 | 動作 |
|---|---|
| 完整流程：取料 → 放上煎台 → 翻面 | 一次規劃好整段，動作連續：左鏟放下肉排後直接鏟回去翻面 |
| 取料放上煎台 | 只做取料、放上煎台 |
| 翻面 | 只翻煎台上那片 |
| 重設 | 清空煎台、托盤補滿 |
| 從煎台開始 | 不經過取料，直接在煎台設定位置放一片（開發初期 / 除錯用） |
| 停止 | 中斷動作或規劃 |

每個動作都會先規劃整條路徑（逆運動學 + 每一步碰撞檢查，兩支手臂互相也算），全部可行才開始動。
完整流程約 30～60 秒、單獨翻面約 5～20 秒；不行的話面板會列出每個方向是哪支手臂、哪一段、哪個零件會撞到什麼。
速度滑桿控制播放速度。

肉排顏色：生的兩面都是肉色；放上煎台後朝下（正在煎）的那面變深褐色，翻面後褐色那面朝上。

### 取料（兩把平鏟）與完整流程

左臂的鏟子當盤子接著端，右臂的鏟子刮：

| 階段 | 動作 |
|---|---|
| 左鏟移到托盤 | 鏟面放平貼托盤（離 1 mm），鏟尖朝向肉排、停在肉排前 10 mm |
| 右鏟移到肉排後面 | 從另一邊過來，鏟尖朝下 45°（像一面牆），鏟尖離托盤 3 mm |
| 右鏟把肉排刮上左鏟 | 右鏟往左鏟推，肉排滑上左鏟鏟面；推到兩個鏟尖相距 8 mm |
| 右鏟抬起、左鏟端起肉排 | 右鏟抬 120 mm，左鏟端著肉排抬起「抬高」的距離 |
| 搬到煎台 | 左鏟一路保持水平（傾斜不超過 30°，不然肉排會滑掉），放平在煎台上，肉排中心對準「煎台上位置」 |
| 右鏟擋在肉排後面 | 右鏟尖擋在肉排正後方，比左鏟鏟面高 6 mm；鏟面往後翹 45° 或斜靠在肉排上方 60°，挑手臂動得少的 |
| 左鏟抽出、肉排落到煎台 | 左鏟往後抽，肉排被右鏟擋住，鏟尖抽過肉排中心時肉排落到煎台 |
| 右鏟抬起、回到托盤上方 | 讓出煎台，準備刮下一片（回不去才回出發位置） |
| 翻面（完整流程才有） | 左鏟就在肉排後面、鏟面貼著煎台，直接往前鏟回肉排底下，抬起、翻鏟、退回（見下面「翻面」） |

只按「取料放上煎台」時，最後左鏟也抬起、回到出發位置。
刮的方向（在托盤上）和放的方向（在煎台上）會自己找，每 30° 試一次，先試兩支手臂動得最少的；右鏟在托盤上的手臂姿勢會挑和等一下在煎台擋肉排時同一邊（手肘、手腕），避免中間整個翻過去。完整流程的翻面先試和放下同一個方向（鏟子不用抬起來）。
兩把平鏟之間只要隔 5 mm（碰撞檢查的取樣間距）就算沒撞到，手臂其他部分還是用安全距離。

### 翻面

1. 「煎台上位置」是肉排放在煎台上的位置（煎台座標，原點是煎台頂面中心），也是取料放下的位置。翻面前另一支手臂要在旁邊不擋路（取料結束時兩支都會回到出發姿態）。
2. 翻面動作：

   | 階段 | 動作 |
   |---|---|
   | 移到肉排旁 | 鏟面放平，停在肉排前方 30 mm、煎台上方 150 mm |
   | 下降 | 直線降到離煎台面 1 mm |
   | 鏟進肉排底下 | 貼著煎台往前推，鏟尖超過肉排 10 mm，肉排上到鏟面 |
   | 抬起 | 往上抬「抬高」設定的距離（預設 100 mm） |
   | 翻鏟 | 繞把手方向轉 180°，轉軸通過肉排中心，鏟面原地翻過來；翻過 90° 時肉排滑落、翻面落回煎台 |
   | 轉回、退回 | 轉回來，退回肉排旁上方 |

3. 翻完可以再按一次「翻面」，會從肉排現在的位置翻回來。

鏟入方向是鏟尖朝向的角度（煎台座標，0° = 煎台 +X）。勾選「到不了就自動換方向」時，設定方向不行會每 30° 換一個方向再試。
預設尺寸下，右臂用 180°（從 +X 側往 -X 鏟）、左臂用 0° 都可以翻。

### 簡化的地方

- 肉排不算碰撞物，也沒有物理：翻面時鏟面推進肉排不會被推走，鏟完才「放上」鏟面；刮的時候肉排跟著刮的鏟子平移，到底才放上接的鏟面。
- 掉落時間用自由落體估算，落點是那一刻肉排中心的正下方，每翻一次會偏移約 9 mm。
- 實際機器翻鏟的速度、甩的力道、生肉排刮起來會不會黏在托盤或鏟面上、會不會變形，都要實測；這裡只驗證路徑可行、不會撞。
- 放上煎台的位置和設定差約 5 mm。
- 還沒有視覺：托盤上每片的位置是用設定算出來的。

## 煎台

煎台位置還沒定，目前放在世界座標 X 0、Y 600、頂面高 850 mm，600 × 400 × 60 mm（實際值以 `config/scene.yaml` 為準）。

- 在面板的「煎台」欄位改位置、旋轉、長寬厚，RViz 會立刻更新。
- 按「儲存設定」會寫回 [smartcook_v2_description/config/scene.yaml](smartcook_v2_description/config/scene.yaml)（連同工具、平鏟、夾爪、托盤、碰撞、肉排設定），下次開啟就用新的值。記得把這個檔 commit。
- 也可以直接改這個 yaml 再重新開啟模擬。

## 安裝位置

立柱頂端兩側各有一塊 190 × 250 mm 的安裝板（x = ±58 mm，z 1014～1204 mm），RS007L 腳座 190 × 220 mm 剛好對上。
每支手臂的底座朝外（base_link 的 Z 軸垂直安裝板），關節全部歸零時手臂水平往外伸。

| 手臂 | 安裝板 | 關節名稱 |
|---|---|---|
| `right_` | +X 側 | `right_joint1`～`right_joint6` |
| `left_` | -X 側 | `left_joint1`～`left_joint6` |

左右是假設從 -Y 方向看底座，跟實際不同的話再對調。

位置用啟動參數調整（單位 m、rad），兩側對稱一起改：

| 參數 | 預設 | 說明 |
|---|---|---|
| `plate_x` | 0.058 | 安裝板面到立柱中心的距離 |
| `mount_y` | 0.108 | 讓 RS007L 腳座中心對齊安裝板中心（y = 120 mm） |
| `mount_z` | 1.109 | 安裝板中心高度（CAD 座標） |
| `mount_roll` | 0.0 | 手臂在安裝板上繞自己 Z 軸轉的角度 |

例如把手臂在板上轉 90°：

```bash
wsl -d Ubuntu -- bash -c "source ~/smartcook_ws/install/setup.bash && ros2 launch smartcook_v2_description display.launch.py mount_roll:=1.5708"
```

要改預設值，改 [smartcook_v2_description/urdf/smartcook_v2.urdf.xacro](smartcook_v2_description/urdf/smartcook_v2.urdf.xacro) 和 `launch/display.launch.py`（兩邊要一致）。

## 檔案

- `smartcook_rviz_plugins/`：RViz 外掛（C++），右鍵平移的 Orbit 視角
- `smartcook_v2_description/scripts/jog_panel.py`：吋動面板，同時發佈 `/joint_states`、煎台標記 `/smartcook_scene`、TF（`griddle`、`right_tcp`、`left_tcp`）
- `smartcook_v2_description/config/scene.yaml`：煎台、托盤位置與尺寸，兩支手臂的工具，平鏟、夾爪尺寸，碰撞設定，肉排與翻面設定
- `smartcook_v2_description/meshes/robot_base.stl`：底座模型，複製自 `V2/圖檔/robot base.stl`（和 `robot_base.step` 尺寸相同，單位 mm）。底座改版後要重新匯出 STL 並覆蓋這個檔。
- RS007L 模型不在這個 repo：它是 Kawasaki 的 CAD 授權，由 `setup_wsl.sh` 下載到 WSL。
  setup 會拿掉 Kawasaki 巨集裡的 White / Black 材質定義（改由我們的 xacro 定義一次），否則兩支手臂會重複定義、URDF 解析失敗。
