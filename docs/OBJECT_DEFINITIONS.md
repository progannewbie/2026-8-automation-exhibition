## 食材定義

### 三種食材清單

| 英文名 | 中文名 | 切割方法 | 建議厚度/長度 | 用途 |
|--------|--------|--------|-------------|------|
| `CUCUMBER` | 小黃瓜 | 切片 (SLICE) | 4 mm | 新鮮爽脆 |
| `ROMAINE` | 蘿蔓生菜 | 分段 (SEGMENT) | 25–30 mm | 爽脆葉菜 |
| `RED_LEAF` | 紅捲鬚生菜 | 聚攏 (GATHER) | 不切 | 色彩豐富 |

### 食材詳細規格

#### 小黃瓜 (CUCUMBER)

```python
FoodType.CUCUMBER
```

**物理特性**:
- 形狀：細長圓柱型
- 長度：約 200–250 mm
- 直徑：約 30–40 mm
- 典型重量：200 g
- 顏色：綠色

**切割參數**:
- 方法：SLICE (縱向切片)
- 片厚：4–6 mm
- 刀數：依長度決定，通常 5–8 片
- 工具：左鏟（開刃）

**特殊處理**:
- 右鏟需壓住食材，防止滾動
- 每刀後逐步後移壓點

---

#### 蘿蔓生菜 (ROMAINE)

```python
FoodType.ROMAINE
```

**物理特性**:
- 形狀：長條狀束集葉菜
- 長度：約 250–300 mm
- 寬度：約 80–100 mm
- 典型重量：300 g
- 顏色：綠色

**切割參數**:
- 方法：SEGMENT (分段)
- 段長：25–30 mm
- 切數：依長度決定，通常 6–10 段
- 工具：左鏟（開刃），自葉尖向根部切

**特殊處理**:
- 停止位置：距根部 50–60 mm (保留根部整體)
- 右鏟將根部段撥至廢料角
- 切段聚攏併入混拌區

---

#### 紅捲鬚生菜 (RED_LEAF)

```python
FoodType.RED_LEAF
```

**物理特性**:
- 形狀：結球菜，鬚狀葉
- 直徑：約 150–200 mm
- 典型重量：400 g
- 顏色：紅紫色

**處理方法**:
- 方法：GATHER (聚攏，**不切**) 
- 工具：雙鏟協作低角度切入葉團底部，對合成托
- 搬運至混拌區

**特殊處理**:
- 不進行切割，保持原形
- 直接聚攏併入沙拉
- 注意葉片易散，雙鏟對合保穩定

## 工具定義

### 兩把鐵鏟配置

| 代號 | 中文名 | 對應臂 | 特性 | 主要功能 |
|------|--------|--------|------|---------|
| `LEFT_SPATULA` | 左鏟 | F60_F (左臂) | **開刃**，有切削能力 | 切割 |
| `RIGHT_SPATULA` | 右鏟 | F60_R (右臂) | **平面**，無切削能力 | 壓菜、聚攏、托運 |

### 左鏟 (LEFT_SPATULA)

```python
ToolType.LEFT_SPATULA
```

**物理規格**:
- 臂：F60_F (左臂)
- 刃面：開刃（有切削能力）
- 研磨角：約 45°（估計）
- 長度：約 250 mm
- 寬度：約 60 mm

**功能**:
- **CHOP**: 下壓切割（主要）
- **CUT**: 牽引切割（備用）

**使用場景**:
1. 小黃瓜：逐刀下壓薄片
2. 蘿蔓：自葉尖向根部分段切割

---

### 右鏟 (RIGHT_SPATULA)

```python
ToolType.RIGHT_SPATULA
```

**物理規格**:
- 臂：F60_R (右臂)
- 刃面：平面（無切削能力）
- 長度：約 250 mm
- 寬度：約 60 mm

**功能**:
- **HOLD**: 壓住、固定食材（主要）
- **PUSH**: 推動、聚攏食材
- **GATHER**: 聚攏多種食材
- **SCOOP**: 鏟起、托運

**使用場景**:
1. 小黃瓜：自上方壓住，隨切割步進後移
2. 蘿蔓：下壓整株，防止亂散
3. 紅捲鬚：底部托運
4. 翻炒：與左鏟互補翻動
5. 裝盤：托底 + 左鏟推料傾倒

```python

```

- **約束**:

  - 與紅捲鬚距離 ≥ 80 mm

## 座標系統

### 坐標系定義

```
視圖：俯視圖（從上往下看）

                  Y (朝向觀眾)
                  ^
                  |
                  |
      --+--------+------
        |        |
        |   工作 | 沙拉盤
        |   區   |
        |        |
--+-----O--------+-------> X (向右)
  | (0,0)
  | 檯面左下角
```

| 軸 | 方向 | 意義 |
|----|------|------|
| **X** | → (向右) | 水平正方向，沿檯面寬度 |
| **Y** | ↑ (向前) | 水平朝向觀眾，沿檯面深度 |
| **Z** | ↑ (向上) | 垂直向上 |

### 單位

- **座標**: 毫米 (mm)
- **角度**: 度 (°)，範圍 0° ~ 360°

### 方向角定義

食材或工具的**長軸與 X 軸**的夾角（逆時針為正）:

```
0°    : 平行 X 軸，朝向右 (→)
90°   : 平行 Y 軸，朝向前 (↑)
180°  : 平行 X 軸，朝向左 (←)
270°  : 平行 Y 軸，朝向後 (↓)
```

## 現場標定流程

### 標定時機

- **時間**: S1 期間 (7/21–7/24)
- **人員**: Zhang (軟體) + Wilson (視覺)
- **工具**: 相機、YOLO 模型 v1、手量尺、ArUco 標記

### 標定步驟

#### 步驟 1: 相機標定 (Camera Calibration)

1. 設置相機俯拍固定位置
2. 拍攝棋盤標定板多角度照片
3. 執行相機內參標定 (OpenCV `calibrateCamera()`)
4. 得到相機矩陣 K 與畸變係數

#### 步驟 2: ArUco 基準點標定

1. 在工作區和沙拉盤各貼一張 ArUco 標記 (ID: 101, 102)
2. 用相機拍攝，檢測 ArUco ID 與像素位置
3. 紀錄 ArUco 在現實檯面的座標 (已知值或手工測量)
4. 建立像素座標 ↔ 現實座標的映射表

#### 步驟 3: 食材位置標定 (Food Position Calibration)

1. 按棋盤式擺放三種食材：
   - 小黃瓜在左下
   - 蘿蔓在中上
   - 紅捲鬚在右下
2. 用 YOLO v1 檢測三種食材，記錄：
   - 中心點像素座標 (u, v)
   - 物體長軸方向角 (θ_pixel)
3. 透過 hand-eye 轉換矩陣，將像素座標轉換為現實座標 (X, Y)
4. 紀錄三個 `PICKUP_*` 位置點的座標與角度

#### 步驟 4: 工作區功能區標定

1. **WORK_CHOP_ZONE**: 測量並紀錄切割區中心
2. **WORK_MIX_ZONE**: 定義為工作區稍後的位置（混拌食材用）
3. **WORK_FLIP_ZONE**: 定義為翻炒時鏟子的互補中心

#### 步驟 5: 放置區標定

1. **SALAD_BOWL**: 測量沙拉盤中心座標
2. **WASTE_CORNER**: 定義廢料角位置

#### 步驟 6: 手臂位置點標定

1. 使用示教盒或直接驅動，將兩臂移動到各位置點
2. 紀錄 F60 內部的關節角度 (若需要) 或笛卡爾座標
3. **HOME_LEFT** 和 **HOME_RIGHT** 需特別注意高度與干涉

### 標定數據表單

見 **CALIBRATION_POINTS.csv**（下一節）

## 檢測與驗證

### YOLO 類別對應

| 類別 ID | 英文名 | 中文名 |
|---------|--------|--------|
| 0 | CUCUMBER | 小黃瓜 |
| 1 | ROMAINE | 蘿蔓生菜 |
| 2 | RED_LEAF | 紅捲鬚生菜 |

### ArUco 標記對照

| 標記 ID | 名稱 | 用途 |
|---------|------|------|
| 101 | WORK_ZONE_REF | 工作區基準標記 |
| 102 | SALAD_BOWL_REF | 沙拉盤基準標記 |

### 精度要求

| 項目 | 要求 |
|------|------|
| **視覺定位精度** | ±5 mm (YOLO) |
| **hand-eye 精度** | ±3 mm |
| **位置點精度** | ±10 mm |
| **方向角精度** | ±5° |

### 驗證測試

```
步驟 1: 擺放三種食材於取料區
步驟 2: 執行 YOLO 檢測，取得三個位置點
步驟 3: 將像素座標透過 hand-eye 轉換為現實座標
步驟 4: 與手工測量值對比，誤差應 ≤ ±3 mm
步驟 5: 若誤差過大，重新標定或調整轉換矩陣
```

## 使用範例 (Python)

```python
from config_objects import (
    LocationPoint, FoodType, ToolType,
    get_location_coordinates, get_location_angle,
    get_food_name, LOCATION_METADATA
)

# 查詢小黃瓜取料點座標
coords = get_location_coordinates(LocationPoint.PICKUP_CUCUMBER)
print(f"小黃瓜取料點: {coords}")  # 例如 (150.5, 200.3)

# 查詢食材名稱
food_name = get_food_name(FoodType.CUCUMBER)
print(f"食材: {food_name}")  # 輸出 "小黃瓜"

# 查詢位置點方向角
angle = get_location_angle(LocationPoint.PICKUP_ROMAINE)
print(f"蘿蔓方向角: {angle}°")  # 例如 45.0°

# 遍歷所有位置點
for loc in LocationPoint:
    metadata = LOCATION_METADATA[loc]
    print(f"{metadata['name']}: {metadata['description']}")
```
